# 求职助手工作台（Job Assistant Workbench）

一个**纯前端、本地运行、零依赖**的求职全流程交互工作台。把「设置求职者背景 → 匹配度评估 → 简历定制 → 提升规划 → 模拟面试」串成一条可直接操作的工作流。

> 数据全部保存在你本机浏览器（localStorage），不调用任何后端、不需要 API Key，也不向外发送任何信息。

## 快速开始

直接用浏览器打开 `web-app/index.html` 即可，无需安装、无需构建、无需联网。

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 🏠 总览 | 上传简历/背景文件或粘贴文本，一键**提取并生成「求职者画像」**；画像驱动后续所有模块。 |
| 🧠 AI 智能评估 | 粘贴岗位 JD，自动从画像出发做能力模型评估：硬性门槛、软实力评分、亮点/风险、面试重点。 |
| 📊 快速评估 | 离线关键词匹配，秒级给出 JD 与画像的匹配度，无需等待。 |
| 📝 简历工作台 | 从画像自动**预填**简历（姓名/教育/技能/项目/经历），可按岗位侧重重排；手工修改不会被覆盖。 |
| 📚 提升规划 | 基于评估缺口生成针对性提升计划。 |
| 🎤 模拟面试 | 根据岗位与画像短板，生成结构化面试题、答题要点与追问。 |

## 核心数据流

```
求职者背景（上传文件 / 粘贴文本）
        │  本地规则解析
        ▼
   求职者画像  ──►  AI 智能评估  ──►  提升规划 / 模拟面试
        │
        ▼
      简历工作台（自动预填）
```

- **求职者画像**是唯一的数据入口，一旦生成，其余模块自动复用，无需重复输入。
- 支持的文件类型：`.docx`、`.txt`、`.md`、`.csv`、`.json`（docx 文本自动解压提取）。

## 隐私与合规

- 所有解析、评估、简历生成均在浏览器本地完成。
- 除你显式导出（复制 Markdown / 打印 PDF）外，没有任何数据离开本机。
- 编辑区不预置任何他人敏感信息；旧版本含演示数据的浏览器缓存键已升级，不会被读取。

## 技术说明

- 单文件应用：`web-app/index.html`（HTML + CSS + 原生 JS，内联）。
- 无第三方运行时依赖、无构建步骤、无服务端口。
- 不兼容环境：需支持现代浏览器（ES6、Canvas、Clipboard API）。
